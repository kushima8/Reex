# Reex 追加キーコード一覧
 
Reexで使用できる独自キーコードの一覧です。  
RemapまたはVIAでキーに割り当ててご使用ください。  
  
## トラックボール
 
### 設定の保存・リセット
 
| キーコード | 説明 |
|------------|------|
| `REC_RST` | センサー設定[^1]をリセット |
| `REC_SAVE` | 現在のセンサー設定[^1]をEEPROMに保存 |
 
### CPI（カーソル速度）
 
| キーコード | 説明 |
|------------|------|
| `CPI_I100` | CPIを100増加（最大3500） |
| `CPI_D100` | CPIを100減少（最小100） |
| `CPI_I1K` | CPIを1000増加（最大3500） |
| `CPI_D1K` | CPIを1000減少（最小100） |
 
### スクロール
 
| キーコード | 説明 |
|------------|------|
| `SCRL_TO` | 押すたびにスクロールモードのON/OFFを切り替え |
| `SCRL_MO` | 押している間だけスクロールモード |
| `SCRL_DVI` | スクロール除数を1つ上げる（最大 D7 = 1/128、最も遅い） |
| `SCRL_DVD` | スクロール除数を1つ下げる（最小 D0 = 1/1、最も速い） |
| `SSNP_VRT` | スクロールスナップを垂直方向に固定 |
| `SSNP_HOR` | スクロールスナップを水平方向に固定 |
| `SSNP_FRE` | スクロールスナップを無効化（自由スクロール） |
 
### 自動マウスレイヤー
 
| キーコード | 説明 |
|------------|------|
| `AML_TO` | 自動マウスレイヤーのON/OFFを切り替え |
| `AML_I50` | 自動マウスレイヤーのタイムアウトを50ms増加（最大1000ms） |
| `AML_D50` | 自動マウスレイヤーのタイムアウトを50ms減少（最小100ms） |

#### 動作

自動マウスレイヤーのONの状態で、トラックボールを転がすと**レイヤー3**に自動で切り替わり、操作をやめてから設定時間（初期値650ms）が経過すると元のレイヤーに戻ります。  
レイヤー3にマウスボタンやスクロールを割り当てておくことで、レイヤー切り替えキーを押さずにマウス操作ができます。  

レイヤー3では、以下のキーがトラックボールを止めた状態でもレイヤーを維持します。  
マウス操作を続けるためのキーとして扱われるためです。  

- マウスボタン（`KC_BTN1`〜`KC_BTN8`）
- `SCRL_MO`
- 修飾キー（Ctrl / Shift / Alt / GUI）

上記以外のキーを割り当てた場合、押した時点でレイヤー3が解除され、下のレイヤーのキーが入力されます（トラックボールを動かしながら押した場合はレイヤー3のキーが入力されます）。  
そのため、レイヤー3には上記のキーを割り当てることを推奨します。  

なお、キーを押した直後の約200msはトラックボールを動かしてもレイヤーが切り替わりません。  
タイピング中に手が触れてしまった際の誤動作を防ぐための仕様です。  
 
[^1]: CPI、スクロール除数、自動マウスレイヤーのON/OFF状態、および自動マウスレイヤーのタイムアウト
